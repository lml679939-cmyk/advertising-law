## 如何貢獻

### 方式一：回報錯誤或建議（最簡單，不需寫程式）

1. 到 [Issues](https://github.com/lml679939-cmyk/advertising-law/issues) 頁面，點「New issue」
2. 說明題目編號、錯誤內容，以及正確的法條或解析
3. 維護者會確認後修正並更新到題庫

> 例：「期末是非第30題，答案應為 O，因為依處理原則§8……」

---

### 方式二：Pull Request（直接修改檔案）

這是最快讓修正上線的方式。不熟悉 git 也沒關係，GitHub 網頁介面就可以完成：

#### 步驟一：Fork 這個 Repo

點右上角的「Fork」按鈕，把這個 repo 複製到你自己的 GitHub 帳號下。

#### 步驟二：在你的 Fork 中修改 HTML

- **期末考題目**在 `final/index.html`
- **期中考題目**在 `index.html`

點進檔案後，點右上角的鉛筆圖示（✏️ Edit this file）即可在網頁上直接編輯。

#### 步驟三：新增或修改題目

題目資料位於 JavaScript 陣列中，格式如下：

**是非題** — 加在 `const questions = [...]` 陣列最後

```javascript
{
  q: "依消費者保護法第51條，企業因重大過失致消費者受損，懲罰性賠償上限為三倍。",
  ans: "O",
  exp: "消保法§51：故意→五倍；<strong>重大過失→三倍</strong>；一般過失→一倍。",
  page: "p.142 消保法§51"
}
```

**選擇題** — 加在 `const mcQuestions = [...]` 陣列最後

```javascript
{
  q: "依消費者保護法第51條，企業「故意」致消費者受損時，懲罰性賠償上限為何？",
  options: ["一倍", "三倍", "五倍", "十倍"],
  ans: 2,   // 0=A, 1=B, 2=C, 3=D
  exp: "消保法§51：故意→<strong>五倍</strong>以下；重大過失→三倍；一般過失→一倍。",
  page: "p.142 消保法§51"
}
```

**填充題** — 加在 `const fillQuestions = [...]` 陣列最後

```javascript
{
  q: "消費者保護法第51條：企業故意時，懲罰性賠償上限為___倍；重大過失為___倍。",
  blanks: [["五", "5"], ["三", "3"]],   // 每格列出所有可接受的寫法
  answers: ["五（5）倍", "三（3）倍"],  // 顯示用答案
  exp: "消保法§51：<strong>故意→五倍；重大過失→三倍；一般過失→一倍</strong>。",
  page: "p.142 消保法§51"
}
```

> **page 欄位格式：** `"p.頁碼 法條名稱"`，頁碼對應課程 PDF 講義。若法條不在講義 PDF 中（如施行細則、子辦法），直接填法條名稱並加上 `（衍生法規/考古題）`，例如 `"廣告插播辦法§3（衍生法規/考古題）"`。

> **題目來源標記：** 不加任何屬性 = 考古題（預設）。若是 AI 生成或自擬的補充題，請加上 `ai: true`，這樣學生可以用篩選鍵區分兩類題目。

#### 步驟四：送出 Pull Request

1. 在你的 Fork 頁面，點「Contribute」→「Open pull request」
2. 填寫說明：修改了哪幾題、依據哪條法規
3. 送出後，維護者審核確認後合併，約 1 分鐘後上線

---

### 方式三：Fork 建立你自己的題庫

如果你有不同科目（例如勞動法、醫療法規）或其他課程，可以 Fork 這個 repo 自行維護：

1. Fork → 到你的 repo 設定 → Pages → 選 `main` branch → Save
2. 修改 HTML 中的課程名稱、題目陣列、法規分類
3. 推送後自動部署，約 1 分鐘生效

整個專案是單一 HTML 檔案，不需要後端、不需要資料庫，只需要靜態網頁空間（GitHub Pages 免費）。

## 本地開發預覽

```bash
# clone 到本地
git clone https://github.com/lml679939-cmyk/advertising-law.git
cd advertising-law

# 啟動本地伺服器（需要 Python 3）
python -m http.server 8080

# 瀏覽器開啟
# 期中考：http://localhost:8080/
# 期末考：http://localhost:8080/final/
```
